# Enxame

Skill de coordenação de trabalho de engenharia para Claude Code, Codex e Antigravity: quando delegar, como passar contrato, como retomar trabalho interrompido e como revisar sem histórico. Faz diretamente por padrão e só delega o que é independente e barato de conferir.

- Skill: [SKILL.md](SKILL.md) · Hosts: [references/hosts.md](references/hosts.md)
- Evals: `evals/` (rodam com `claude plugin eval` apontando para um plugin que contenha esta skill)

## Instalar

Copie `SKILL.md` e `references/` para a pasta de skills do host (`~/.claude/skills/enxame`, `~/.agents/skills/enxame` ou `~/.gemini/config/skills/enxame`) e reinicie a sessão. A mesma skill é distribuída como plugin em `playertwo1/skills-and-plugins`.
